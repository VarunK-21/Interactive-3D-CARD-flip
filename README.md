# Professional Portfolio - 3D Flip Cards

A clean and professional portfolio website featuring interactive 3D flip cards with a sophisticated gold and black theme.

## ✨ Features

- **3D Flip Animation**: Smooth horizontal card rotation on hover
- **Professional Design**: Elegant gold and black color scheme
- **High-Quality Images**: Crystal clear professional photography
- **Responsive Layout**: Optimized for all device sizes
- **Clean Typography**: Playfair Display and Inter fonts
- **Interactive Elements**: Hover effects and smooth transitions

## 🎯 Core Requirements

- Semantic HTML structure with proper accessibility
- CSS 3D transforms (`rotateY`, `perspective`, `transform-style`)
- Smooth transitions (0.6s ease animation)
- Backface visibility control
- Professional visual design

## 🚀 Getting Started

1. Clone or download the project files
2. Open `index.html` in your web browser
3. Hover over the cards to see the 3D flip effect

## 📁 Project Structure
